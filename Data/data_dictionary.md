# Data Dictionary

## Data_base9.1_CURVE.xlsx

Dataset used for cumulative drug release prediction. Each row represents a release profile or time-dependent release information extracted from the literature.

## Data_base9.2_EE.xlsx

Dataset used for encapsulation efficiency prediction. The target variable is encapsulation efficiency percentage.

## Main variables

- CS_MW_kDa: Chitosan molecular weight.
- CS_DD_percent: Degree of deacetylation.
- CS_Conc_wv_percent: Chitosan concentration.
- Crosslinker_Conc_percent: Crosslinker concentration.
- Drug_MW_g_mol: Drug molecular weight.
- Drug_LogP: Drug lipophilicity descriptor.
- Medium_pH: Release medium pH.
- Time_h: Release time in hours.
- Cum_Release_percent: Cumulative drug release percentage.
- EE_percent: Encapsulation efficiency percentage.
